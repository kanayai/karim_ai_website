# Commit Episodes — karim_ai_website

With no transcripts, "episodes" are reconstructed from **same-day Gemini commit clusters** — a run
of commits by the agent on one day is a reasonable proxy for one work session. Evidence is the
commit message + diff, not conversation.

| ID | Episode | Date(s) | Gemini commits | Outcome |
|----|---------|---------|---------------:|---------|
| W1 | Scaffold + publications viewer | 2025-11-23–26 | ~23 | Success, with same-day reverts |
| W2 | VS Code fidelity + interactive extensions | 2025-12-04 | 9 | Mixed — add-then-remove churn |
| W3 | Theming, search, blog UX | 2025-12-07 | 10 | Mixed — feature reverted same day |
| W4 | AI handover → human-only polish | 2026-01-13 → 03 | 6 → 0 | Clean handover, reasoning lost |

Template fields: identity · work type · start condition · AI role · information burden ·
workflow shape · outcome · lessons (project + OS) · evidence.
