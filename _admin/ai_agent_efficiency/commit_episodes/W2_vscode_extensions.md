  features beyond the explicit ask should be flagged and easy to drop. Across both projects this is
  the same failure mode in two evidence forms.
- **Evidence:** Same-day *"Feat: Add interactive extensions…"* and *"Refactor: Remove Theme
  Switcher, update Retro Game to Memory Match, remove LaTeX tip"*.
